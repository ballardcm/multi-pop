# Conservative RG DS library selection

For the initial library transfer, include Atari 2600/5200/7800/Lynx, C64, ColecoVision, Intellivision, Vectrex, NES, SNES, Game Boy/Color/Advance, Master System, Game Gear, SG-1000, Genesis, 32X, Sega CD, PC Engine/TurboGrafx-16 and CD, Neo Geo/Pocket Color, WonderSwan Color, Virtual Boy, PS1, Nintendo DS, and 2D FinalBurn Neo games.

This is a system-level starting point, not a guarantee for every ROM, special-chip game, arcade driver, or DS title. Prefer DraStic for DS and stock ROCKNIX emulator defaults. Validate individual games on hardware before claiming compatibility. No ROMs or BIOS are part of this repository.

Defer N64, PSP, Dreamcast, Saturn, Jaguar, Naomi, Atomiswave and newer systems because performance is game-dependent or exceeds this device's comfortable range. Generic MAME sets and native ports need individual validation. PICO-8 also needs a matching runtime and cart review.

Transfers include associated media and metadata but exclude per-game `.cfg` files so Thor-specific settings do not override RG DS defaults. Do not copy the Thor's global emulator settings or shaders.
